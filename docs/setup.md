# Môi trường đã chọn

- Ngôn ngữ: JavaScript (Node.js 24 để chạy lệnh và logic headless).
- Hiển thị 3D: WebGL2 trong trình duyệt, không cần thư viện ngoài.
- Nền tảng đích: macOS hoặc Linux với Node.js và trình duyệt hỗ trợ WebGL2.

Chạy thử môi trường:

```bash
npm run smoke
npm run dev
```

Mở `http://127.0.0.1:4173/` để xem hình chóp 3D quay. Đây chỉ là phép thử môi trường; luật chơi và lệnh headless chính thức sẽ làm theo PRD-0/Test Contract.
